How bans work

  • Once a setting value has been played, later yamls using that value get it set to random. Leaving a setting out counts as using its default.
  • Number ranges ban by area: the minimum, the maximum, or the bottom, middle or top third of the values in between.
  • random, or equal weights on every value, bans nothing. Other weighted or narrowed randoms count as every value they can land on.
  • progression_balancing is capped at 50. accessibility and item and location lists are never banned.
  • "Pending review" settings are still being judged by the host and may end up forced random.
